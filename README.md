# Cyber APK Analyzer

A cyberpunk-themed APK Analyzer GUI developed using Python and CustomTkinter, designed to simulate Android application metadata analysis through an interactive desktop interface.

## Overview

Cyber APK Analyzer is a beginner-focused cybersecurity GUI project that demonstrates:
- Python GUI development
- Multi-threaded application workflows
- Simulated APK analysis visualization
- Terminal-style logging interface
- Cybersecurity-inspired UI/UX design

The application provides a modern desktop experience for APK inspection simulation while maintaining responsive UI performance through threaded execution.

# How to Run

## Clone Repository

```bash
git clone https://github.com/Brute-Kenzzz/Cyber-APK-Analyzer
```

## Navigate Into Project

```bash
cd Cyber-APK-Analyzer
```

## Install Dependencies

```bash
pip install customtkinter
```

## Run Application

```bash
python main.py
```
